# Projet-moulin-du-Noiret
Site pour la restauration to moulin du Noiret à St-Jorioz

# Comment lancer le projet en local
1. Si pas déja fait installer pnpm avec npm ``npm install -g pnpm``

2. Mettre à jour tout les modules du projet avec ```cd moulin-app;pnpm install```

3. Lancer le serveur dev avec ```cd moulin-app;pnpm run dev```
